# Identité visuelle - IUM-MORAVE (ébauche)

Date: 2026-08-01

Objectif
--------
Définir les éléments visuels et la charte graphique initiale pour assurer une identité cohérente.

Logo
----
- Fournir un logo principal en versions couleur et monochrome.
- Définir règles d'usage, marges minimales et restrictions.

Palette de couleurs
-------------------
- Couleur principale: #0A4D8C (exemple - bleu institutionnel)
- Couleurs secondaires: #F2C94C (accent), #6FCF97 (success), #EB5757 (danger)
- Ne pas utiliser de couleurs criardes.

Typographie
----------
- Famille principale: Inter (web-safe fallback: system sans-serifs)
- Titres: Inter Bold
- Corps de texte: Inter Regular / 16px base

Images & médias
---------------
- Utiliser photographies haute qualité, institutionnelles.
- Optimiser et fournir plusieurs résolutions pour mobile.

Icons & illustrations
---------------------
- Utiliser icônes simples, linéaires et cohérentes.
- Fournir une bibliothèque SVG.

Accessibilité
-------------
- Contraste minimum 4.5:1 pour textes normaux.
- Taille de police base 16px et possibilité d'agrandissement.

Livrables
---------
- docs/IDENTITE_VISUELLE.md (ce document)
- Fichiers logo (SVG/PNG) à ajouter dans /assets/branding/
- Palette et tokens exportés pour le Design System

Prochaine étape
---------------

- Exporter tokens pour DESIGN_SYSTEM.md.
