PARTIE VII — DÉPLOIEMENT, EXPLOITATION ET MAINTENANCE (10 CHAPITRES)

Objectif général de la partie

Définir les conditions nécessaires pour mettre le portail en production, assurer son fonctionnement quotidien et garantir son évolution sur le long terme.

Le projet devra passer progressivement :

du développement initial gratuit sur GitHub ;

à une plateforme officielle professionnelle utilisant un domaine .CD.


---

CHAPITRE 1 — Préparation au lancement

Objectif

Organiser la mise en ligne officielle.

Actions :

validation finale du site ;

contrôle des contenus ;

vérification des fonctionnalités ;

validation par les autorités universitaires.

Livrable :

Version prête pour publication.


---

CHAPITRE 2 — Migration GitHub vers production

Objectif

Passer de l’environnement de développement à l’environnement public.

Étapes :

transfert du projet ;

configuration serveur ;

installation base de données ;

déploiement sécurisé.

Exigence :

Conserver l’historique du développement.


---

CHAPITRE 3 — Configuration du domaine officiel .CD

Objectif

Créer une identité numérique institutionnelle.

Actions :

acquisition du domaine officiel ;

configuration DNS ;

création des emails institutionnels ;

activation HTTPS.

Résultat :

Présence officielle de l’université sur Internet.


---

CHAPITRE 4 — Mise en place de l’hébergement professionnel

Objectif

Garantir performance et disponibilité.

Exigences :

serveur fiable ;

stockage adapté ;

sauvegardes ;

surveillance ;

capacité d’évolution.

Prévoir :

Possibilité de montée en puissance selon le nombre d’utilisateurs.


---

CHAPITRE 5 — Formation des utilisateurs

Objectif

Rendre l’administration autonome.

Former :

administrateurs ;

service communication ;

responsables facultés ;

personnel concerné.

Contenus :

gestion du site ;

publication ;

sécurité ;

maintenance courante.


---

CHAPITRE 6 — Documentation du projet

Objectif

Garantir la continuité.

Documents nécessaires :

guide administrateur ;

guide utilisateur ;

documentation technique ;

procédures de maintenance.

Principe :

Le projet ne doit pas dépendre d’une seule personne.


---

CHAPITRE 7 — Support utilisateur et assistance

Objectif

Assurer l’accompagnement après lancement.

Prévoir :

canal de support ;

gestion des problèmes ;

suivi des demandes ;

résolution des incidents.

Utilisateurs concernés :

étudiants ;

enseignants ;

administration.


---

CHAPITRE 8 — Maintenance corrective et évolutive

Objectif

Maintenir la qualité du portail.

Maintenance corrective :

correction des bugs ;

résolution des erreurs.

Maintenance évolutive :

nouvelles fonctionnalités ;

amélioration UX ;

adaptation technologique.


---

CHAPITRE 9 — Amélioration continue

Objectif

Faire évoluer le portail selon les besoins.

Prévoir :

analyse des statistiques ;

retours utilisateurs ;

nouvelles fonctionnalités ;

optimisation permanente.

Indicateurs :

fréquentation ;

performance ;

satisfaction.


---

CHAPITRE 10 — Plan stratégique d’évolution sur 5 ans

Objectif

Préparer la croissance numérique.

Année 1 :

portail institutionnel officiel ;

contenus académiques ;

actualités ;

documents.

Années 2-3 :

espace étudiant ;

admissions en ligne ;

bibliothèque numérique.

Années 4-5 :

système universitaire intégré ;

application mobile ;

services numériques avancés.


---

Résultat attendu de la Partie VII

 disposer d’un plan clair pour :

développer ;

déployer ;

maintenir ;

faire évoluer le portail.


Le site devra être considéré comme un projet vivant, capable d’accompagner la transformation numérique de l’Institut Universitaire Morave de Mwene-Ditu pendant plusieurs années.

Fin de la Partie VII.
